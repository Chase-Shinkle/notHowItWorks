# Spec Delta

## Purpose

Shows old farm-sim sprites inside the 3D backrooms as flat, camera-facing images, for the "wrong place" feel.

## ADDED Requirements

### Requirement: Farm assets appear as billboards
The system SHALL display old farm-sim assets (such as plots and crops) as flat sprites placed in the 3D rooms that always face the camera.

#### Scenario: Sprite faces the player
- **WHEN** the player moves around a billboarded asset
- **THEN** the sprite keeps facing the camera
